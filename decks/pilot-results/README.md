# pilot-results — pilot results report (art pack: engraving)

A report on a pilot project — here, a 6-week workflow-automation pilot at a
mid-size e-commerce brand: before/after metrics, a weekly trend as an SVG chart,
the dollar impact, and a full rollout plan.

The deck wears the **`engraving`** pack (Atlas — copperplate engraving, indigo
ink on cream laid paper, Prata for display) in the pack's default `editorial`
rhythm: a loud cover on the `hero.webp` balance plate with a numbered legend of
the three headline results on its empty left third; a quiet metrics leaf on laid
paper; a mid trend slide opened by the `band.webp` ornament — the deck's one
ornament; a quiet dollar-impact leaf with the quill spot as marginalia; and a
loud close on the indigo `.art-field`. Every number stays live HTML — the plates
carry no text — so the before/after values are `.art-num`, the cover legend is
built from `.art-leader` dotted rows, and the SVG chart is drawn in the pack's
ink and gold-leaf tokens.

What it demonstrates:

- a business document that is not a sales pitch: it closes the pilot and opens
  the full-contract deal;
- metrics as live fields (`data-nk-field`): the manager adjusts numbers during
  the call, while the chart and money calculation recalculate live;
- `promoteToClientFacts`: final values move to the client profile, so the next
  offer for this client starts with real numbers;
- a pure SVG chart using art-pack token colors, with no charting library.

To build on this deck, copy `decks/pilot-results/` into your working folder and add
`template/naimi-kit/` next to it — see `TEMPLATE-SKILL.md` (or just tell your agent
which deck you want to start from).
